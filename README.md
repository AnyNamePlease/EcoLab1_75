# Отчет по проекту и описание тестов: EcoLab

## 1. Введение и общие сведения

Настоящий документ представляет собой итоговый отчет по выполнению проекта **EcoLab** и описание проведенного комплекса тестирования. Проект направлен на мониторинг экологических показателей и анализ данных с датчиков окружающей среды.

*   **Статус проекта:** Завершен
*   **Тип отчета:** Технический отчет и протокол тестирования
*   **Дата формирования:** Октябрь 2026

---

## 2. Структура проекта

Проект включает в себя следующие ключевые модули:
1.  **Модуль сбора данных (Collector):** Интеграция с IoT-устройствами для получения телеметрии в реальном времени.
2.  **Модуль анализа (Analyzer):** Обработка поступающих данных, выявление аномалий и превышений пороговых значений (например, уровня $CO_2$ или радиационного фона).
3.  **Пользовательский интерфейс (Dashboard):** Веб-приложение для визуализации графиков и формирования сводных отчетов.

## 3. Описание тестов

Для обеспечения корректности вычислений, точности производных и стабильности архитектуры был разработан комплекс модульных и интеграционных тестов (test_main.c).

### 3.1. Тест скалярных функций активации и производных (test_scalar_functions)

Тестирует базовые функции (Sigmoid, ReLU, LeakyReLU) и их производные на наборе данных: [-1000.0, -10.0, -1.0, 0.0, 1.0, 10.0, 1000.0].

**Сигмоид (Sigmoid & SigmoidDerivative)**: Аналитическая производная сравнивается с численной производной, рассчитанной методом центральных разностей с шагом $h = 10^{-6}$:

$$\text{NumDeriv} = \frac{f(x + h) - f(x - h)}{2h}$$

Погрешность не должна превышать $\text{TOLERANCE} = 10^{-4}$.

**ReLU и LeakyReLU**: Проверяется линейная часть и обнуление, а также корректная обработка точек излома ($x = 0$), где стандартные центральные разности не применимы напрямую. Для Leaky ReLU тестируется коэффициент утечки $\alpha = 0.01$.

### 3.2. Тест Softmax, численной устойчивости и матрицы Якоби (test_softmax_and_jacobian)

**Устойчивость к переполнению (Overflow Resistance)**: Проверяется обработка больших значений [1000.0, 1001.0, 1002.0] с использованием трюка вычитания максимального элемента ($max\text{-}subtraction$). Сумма элементов результирующего вектора должна быть равна $1.0$ с точностью до $10^{-6}$.

**Вектор одинаковых элементов**: Тестирование вектора [5.0, 5.0, 5.0, 5.0] (каждый выходной элемент должен строго равняться $0.25$).

**Матрица Якоби (SoftmaxJacobian)**: Каждый элемент аналитически рассчитанной матрицы Якоби $J[i][j]$ проверяется поэлементно путем сравнения с численным дифференцированием по каждому компоненту входного вектора.

### 3.3. Сравнение подходов OOA и SOA для бэкпропа (test_ooa_vs_soa)

Проверяется архитектурная эквивалентность результатов обратного распространения ошибки:

**SOA (Service-Oriented Approach)**: Прямой вызов функции расчета градиента через SoftmaxVectorGrad.

**OOA (Object-Oriented Approach)**: Stateful-слой через IEcoNeuralLayer, кэширующий состояние на шаге Forward и выполняющий Backward.

Выходные градиенты сопоставляются с точностью до $10^{-7}$.

### 3.4. Анализ производительности (test_performance)

Нагрузочный тест измеряет среднее время выполнения поэлементной функции Sigmoid и векторной операции Softmax на векторе размером $N = 10000$ элементов за $100$ итераций.
